# 商店上架素材清单

## 基本信息
- 名称：Figma 中文汉化
- 版本：1.3.0
- 分类：开发者工具 / 生产工具
- 语言：简体中文
- 许可：GPL-3.0（商店须同时提供源代码地址）

## 短描述（≤132 字符）
把 Figma 网页版界面汉化为简体中文：菜单、面板、右键菜单、设置、分享与订阅页。离线词表，不联网。

## 详细描述
Figma 网页版目前没有官方中文界面。本扩展把 Figma 的界面文字替换为简体中文，覆盖文件浏览器、编辑器菜单、图层右键菜单、设计/原型面板、账户设置、分享与订阅页面等。

特点：
- 离线词表 + 上下文规则，不联网、不收集数据；
- 不修改你的设计稿、图层名、文件名和评论；
- 支持一键开关、重新扫描；
- 只在你访问 figma.com 时运行。

## 权限说明
- `activeTab` / `tabs`：读取当前标签页地址，判断是否在 Figma 页面，并向页面脚本发送开关指令。
- `host_permissions`：仅在 `www.figma.com`、`figma.com`、`support-chat.figma.com` 注入翻译脚本。
- `storage`：为后续保存偏好预留。

## 需要的素材
- 图标：16/32/48/128（已生成在 `extension/icons/`）
- 商店截图：建议 1280×800，至少 3 张（编辑器、右键菜单、账户设置）
- 小型宣传图：440×280（可选）
