隐私政策 · Figma 中文汉化

生效日期：2026-10-31

本扩展只在 figma.com（含 support-chat.figma.com 客服 iframe）运行，用于把 Figma 界面文字替换为简体中文。

我们不做什么

  • 不收集任何数据：不上传、不记录、不分析你的账号、文件、设计稿、输入内容或浏览记录。
  • 不联网：词表和翻译规则随扩展打包，本地运行；不使用远程翻译接口。
  • 不修改设计内容：只替换界面文案，不会重命名你的图层、文件或评论，也不会修改画布内容。
  • 没有第三方：无统计 SDK、无广告、无第三方数据共享。

本地存储

仅在你的浏览器本地保存“是否启用中文界面”这一个开关状态。

联系方式

如有问题，请到 GitHub Issues 反馈。
